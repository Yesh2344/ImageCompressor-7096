# ImageCompressor

[![Ruby](https://img.shields.io/badge/ruby-3.2%2B-red.svg)](https://www.ruby-lang.org/en/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**ImageCompressor** is a lightweight, production‑ready command‑line tool written in Ruby that compresses JPEG and PNG images while preserving visual quality. It leverages the powerful `image_processing` and `mini_magick` gems and follows modern Ruby best practices, including structured logging, environment‑driven configuration, and comprehensive test coverage.

## Features

* Lossy JPEG compression with configurable quality.
* PNG quantization (lossless or lossy) using `pngquant`.
* Batch processing via glob patterns.
* Structured logging (stdout & file).
* Environment‑based configuration (`.env`).
* Full RSpec test suite.
